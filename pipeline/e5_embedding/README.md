# E5 한국어 임베딩 품질

선배 수기로 질의했을 때, 그 선배가 다녀온 기관의 2026-2 직무가 상위 5개 안에 드는지(Hit@5) 봅니다. E2 결과가 먼저 있어야 합니다.

```
pip install openpyxl requests
python hit_at_k.py --jobs-xlsx "<...>/2026학년도 2학기 표준 현장실습학기제 참여기관 리스트(상시 업데이트 진행중).xlsx" --provider tfidf
VOYAGE_API_KEY=... python hit_at_k.py --jobs-xlsx "<...>.xlsx" --provider voyage
OPENAI_API_KEY=... python hit_at_k.py --jobs-xlsx "<...>.xlsx" --provider openai   # 비교용(선택)
```

- **직무 문서**: 리스트의 기관명, 실습부서·직무내용, 요구역량으로 만듭니다. 선호 전공 열은 일부러 뺐습니다. 넣으면 학과명 일치만으로 맞히게 되기 때문입니다.
- **질의 activities**: 수기의 실습 내용입니다. 학생이 쓴 글과 기관이 쓴 직무 설명의 의미가 맞는지 봅니다.
- **질의 major**: 학과명만 넣습니다. 기획안 M4 검증 원안입니다.
- **판정**: `tfidf`(API 없이 도는 글자 n-gram 기준선)보다 뚜렷이 높고 무작위 기대치의 2배 이상이면, 임베딩을 쓸 이유가 있다고 봅니다. `tfidf`와 비슷하면 임베딩 없이 키워드·태그 매칭으로 갑니다.
- **비용**: Voyage `voyage-4-lite`는 무료 2억 토큰 안이라 0원입니다.
- **정답 기준**: 수기는 과거 학기라 2026-2 직무와 1:1로 대응하지 않습니다. 그래서 기관 단위로 맞았는지 봅니다. 연결되는 수기는 17건뿐이라 결과는 방향만 참고합니다.
