# E2 참여수기 추출

우수 참여수기 PDF 4건(78쪽, 전부 이미지)에서 실습생별 학기, 기관, 부서, 학과, 학년, 실습 내용, 결과, 소감을 뽑습니다. 결과는 M4 추천의 근거 인용과 E5(임베딩 품질) 질의로 씁니다.

## 실행

```
pip install anthropic pypdf pymupdf
# 1) 48.9MB짜리 2025-1 수기는 요청 한도(32MB)를 넘으므로 먼저 압축 (150dpi JPEG, 5.0MB로 줄어드는 것 확인함)
python compress_pdf.py "<...>/3. 우수 참여수기/[2025-1학기] 현장실습학기제_우수 참여수기 모음.pdf"
# 2) 추출 — 폴더를 주면 *수기*.pdf 를 찾고, _small.pdf 가 있으면 원본 대신 씁니다
python run_extract.py "<...>/3. 우수 참여수기"
# 3) 채점
python score.py
# 4) 실습 결과에서 사실 구절만(원문 그대로) → out/outcomes.json — 시드 build_seed.py --outcomes 입력
python extract_outcomes.py
```

비용은 78쪽 기준 약 $0.6~1입니다(쪽 이미지 1장당 약 2,300 입력 토큰 + 39명분 출력).

## 확인하는 것

| 지표 | 기대값 | 근거 |
|---|---|---|
| 수기 건수 | 학기별 10 / 10 / 9 / 10, 총 39건 | 1인 = 글 쪽 + 사진 쪽. 쪽수 20 / 20 / 18 / 20 |
| 2026-2 참여기관 연결 | 17건: 소서 4, 델타텍코리아 3, 위아프렌즈 3, 스미스 2, 오뷔엘알 2, 챔프스터디·더에스엠씨·빌딩닥터엔지니어링 각 1 | 기획안 5장 분석 |
| 사람 판정 | 90% 이상 | `review_records.csv`에서 기관·부서, 학과·학년, 실습내용을 원본과 대조 |

기관 연결은 과거 명칭도 반영합니다. ㈜원오세븐은 소서로, 세정 OL디자인팀은 오뷔엘알로 봅니다. 규칙은 `score.py`의 `link_2026_2`에 있습니다.

## 실습 결과(사실 구절만, `extract_outcomes.py`)

수기는 '우수' 수기만 모은 것이라 좋은 이야기 쪽으로 치우쳐 있습니다. 그래서 기관을 평가하는 데는 쓰지 않고 실제 업무 근거로만 씁니다(기획안 8장). 실습 결과 문단도 같은 원칙으로, **확인할 수 있는 사실**(만든 결과물, 맡은 일, 참여한 프로젝트, 채택된 제안)만 남깁니다(ADR-0020).

- 입력은 3)까지의 `out/*.json`의 `results` 글입니다. PDF를 다시 읽지 않습니다. 39건 약 $0.3(Sonnet 5.5).
- LLM이 원문에서 그대로 자른 구절 0~3개를 코드가 다시 거릅니다: 원문에 끊김 없이 있는지, 60자 이내인지, 감상·배운 점·평가·개인 진로(입사·채용 등)·1인칭 낱말이 없는지, 문장 중간에서 끊긴 꼴('~할 때', '~하고')이 아닌지. 버린 구절은 이유와 함께 `dropped`에 남습니다.
- 끝나면 `out/outcomes.json`을 훑어 남은 구절이 사실인지 봅니다. 시드에 들어간 값은 `seed.json`의 `testimonial[].outcomes`에서 다시 볼 수 있습니다.
