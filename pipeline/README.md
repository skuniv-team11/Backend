# pipeline — 오프라인 데이터 작업과 선행 실험

서비스가 실행 중에 부르지 않는 작업은 모두 여기서 로컬로 돌리고, 결과를 검수해 시드로 확정합니다.

```
pip install -r requirements.txt
```

## 현황 (10/1)

E1·E2·E3·E6 합격, 운영계획서 18건 본 추출과 시드(`seed/`)까지 끝났습니다. 남은 것은 E5(Voyage 키 발급됨)와 도로명주소 좌표(대기)입니다. 결과 수치는 저장소 루트 `README.md` '선행 실험 현황'에 있습니다.

## 처음부터 다시 돌릴 때 순서

1. **키 발급을 먼저 걸어 둡니다.** 공공데이터포털 두 건(국세청, NCS)은 반영까지 시간이 걸릴 수 있습니다. 도로명주소 좌표(검색 API + 좌표제공 API)는 10/1부터 대기입니다(`e6_external/README.md`).
2. **E1은 선도소프트 1건만 먼저 돌립니다.** API와 스키마가 받아들여지는지 확인한 뒤 나머지 4건을 돌립니다.
3. E2를 돌립니다. 2025-1 수기는 먼저 압축합니다.
4. E3를 돌립니다(저장소 루트에서 `spike` 프로필, `README.md` 참고).
5. E5는 E2가 끝난 뒤, E6는 키가 나오는 대로 돌립니다.

## 공개 저장소 주의

실험 결과(`out/`, `review_*.csv`, `e*_report.md`)와 정답셋(`e1_operation_plan/data/`), E6 결과 CSV에는 사업자번호처럼 화면에 안 나오는 값이 들어 있습니다. 루트 `.gitignore`가 이 파일들을 빼 둡니다. 원본 PDF와 엑셀은 저장소 밖에 둡니다.
