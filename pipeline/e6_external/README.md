# E6 외부 데이터 (키 발급 + 1회 적재)

**로컬에서 한 번 돌려 결과 CSV를 시드로 쓰는** 스크립트입니다. 서비스 실행 중에는 부르지 않습니다.

> **통근 시간은 여기서 만들지 않습니다(10/1).** ODsay 운영정책이 사전 동의 없는 결과 저장·가공을 금지해서, 통근은 서비스가 직무 상세를 열 때 카카오 대중교통 API를 실시간으로 부르고 저장하지 않는 방식으로 바꿨습니다([ADR-0007](../../docs/decisions/0007-commute-kakao-live.md)). 여기서는 그 조회에 쓸 **좌표**(근로지, 시·군·구청)만 공공 API로 구합니다. `odsay_commute.py`는 호출 확인용으로만 남겨 두고, 결과(`commute.csv`·`odsay_cache/`)는 시드에 쓰지 않습니다.

| 스크립트 | 키 발급 | 결과 | 쓰임 |
|---|---|---|---|
| `nts_status.py` | 공공데이터포털 → '국세청_사업자등록정보 진위확인 및 상태조회 서비스' 활용신청(자동승인) → **Decoding 키** | `nts_status.csv` (18곳 상태) | M2 휴·폐업 탐지 |
| 좌표 적재(**대기**, 10/1) | [도로명주소 개발자센터](https://business.juso.go.kr) → API 신청 → **검색 API** 승인키(주소 → 코드) + **좌표제공 API** 승인키(코드 → 좌표). 키는 API마다 따로 | `workplaces.csv`·`areas.csv`의 `lat`·`lng` (WGS84) | 통근 조회의 도착점(근로지)·출발점(시·군·구청) |
| `odsay_commute.py` | (보관) ODsay LAB 서버 키 + 본인 PC 공인 IP | `commute.csv` — **시드에 쓰지 않음** | 호출 확인용 |
| `ncs_load.py` | 공공데이터포털 → '한국산업인력공단_NCS 관련 정보' 활용신청(자동승인) → **Decoding 키** | `ncs_units.csv` (능력단위 약 15,520건) | M3 직무 풀이(P1) |

```
pip install requests openpyxl
NTS_SERVICE_KEY=... python nts_status.py
python odsay_commute.py template --jobs-xlsx "<참여기관 리스트.xlsx>"   # 근로지 목록 workplaces.csv 만들기(좌표 적재에도 씀)
NCS_SERVICE_KEY=... python ncs_load.py
```

- **공공데이터포털 키는 Decoding(일반 인증키)을 씁니다.** 스크립트가 URL 인코딩을 한 번 하므로, Encoding 키를 넣으면 두 번 인코딩돼 인증에 실패합니다.
- **발급 직후 반영이 늦을 수 있습니다.** 자동승인이어도 인증 오류가 나면 1~2시간 뒤 다시 해 봅니다.
- **좌표는 공공 API에서만 받습니다.** 카카오·네이버 지도에서 찍은 좌표나 카카오 로컬 API 결과는 저장할 수 없습니다(각 사 운영정책). 행정안전부 좌표제공 API는 이용허락범위 제한이 없습니다.
- **좌표제공 API는 주소 문자열을 받지 않습니다(10/1 확인).** 행정구역코드·도로명코드·지하여부·건물본번·부번을 받으므로, 도로명주소 검색 API로 주소를 먼저 찾아 그 코드를 넘깁니다. 팝업 API가 아니라 검색 API 방식을 씁니다.
- **대기(10/1):** 키 발급과 적재는 미뤄 둡니다. 근로지 좌표(`workplace.lat`·`lng`)는 비어도 되고, 그동안 통근 칸은 '불러올 수 없음'으로 나옵니다. 사는 곳(`area`)은 좌표가 필수라 좌표를 받기 전에는 시드에 넣지 못하므로, 그때까지 통근 출발점은 서경대뿐입니다. 통근 칸을 실제 근로지로 시연하기 전에 재개합니다.
- **좌표계:** 좌표제공 API는 UTM-K(EPSG:5179)로 줍니다. 카카오 대중교통 API는 WGS84를 받으므로 변환해서 넣습니다(변환 라이브러리 추가는 먼저 묻습니다).
- **시·군·구 목록:** 서울·인천·경기 시·군·구를 행정표준코드(5자리) 최신본으로 넣습니다. 2026년에 구역이 바뀐 곳이 있으니 적재 때 코드표를 새로 받습니다. 대표점은 시·군·구청 주소의 좌표입니다.
- **Nominatim 좌표(10/1 E6)는 버립니다.** 간선도로 5행이 도로 단위로 잡혀 정확도가 낮고, 공공 API로 다시 받으면 해결됩니다.
- **API 연결 확인(10/1):** 국세청·NCS·ODsay 모두 실제 키로 응답을 확인했습니다. ODsay 결과는 위 이유로 시드에 쓰지 않습니다.
- **저장소:** `*.csv`와 `odsay_cache/`는 저장소에 올리지 않습니다. 사업자번호가 포함되고, 결과는 시드로 옮깁니다. 로컬의 `commute.csv`·`odsay_cache/`는 ODsay 정책상 지우는 것을 권합니다.
