# 기관 로고 (ADR-0019)

결과물은 `src/main/resources/static/logos/{기관 id}.png`(id는 `seed/curated/ids.json`). 서비스는 실행 중에 이 파일만 내보내고 외부 사이트를 부르지 않는다.

## 만드는 법
1. 아래 출처에서 로고 이미지를 받는다(2026-10-05). 몇몇 사이트는 브라우저와 같은 `User-Agent`·`Referer` 없이 받으면 차단 화면을 준다.
2. 다듬는다: RGBA로 바꿈 → 흰 배경이면 흰색을 투명으로(흰색 기준 color-to-alpha) → 투명 여백을 잘라 내고 짧은 변의 4%(최소 2px) 여백 → 최대 600×200 안으로만 줄인다(키우지 않음) → PNG.
3. 흰 글자 로고(어두운 배경용)는 같은 모양 그대로 색만 어둡게, 검은 바탕 아이콘은 반전해 투명 바탕으로 바꾼다. 모양은 바꾸지 않는다.
