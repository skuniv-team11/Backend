# ADR-0004 공개 저장소의 데이터 범위

- 상태: 확정 (2026-09-30)
- 결정: 원본 문서(PDF·엑셀·hwp), 키, `.env`, 실험 결과, 화면에 안 나오는 필드(사업자번호·대표자명), 학과×직무 매칭 집계는 저장소에 넣지 않는다. 시드에는 화면에 보이는 값과 직무별 배정 수만.
- 이유: 드라이브 공유 범위가 서경대 도메인 한정. 매칭 결과 21명을 학과×직무로 나누면 칸당 1~2명이라 개인 식별 위험(감점 07).
- 강제: `.gitignore`, `scripts/check-secrets.sh`(pre-commit·CI).
