# ADR-0007 통근 시간은 카카오만으로 실시간 계산하고 저장하지 않는다

- 상태: 확정 (2026-10-01), **개정 (2026-10-02 — 좌표도 카카오 주소 검색으로 그때 구한다)**
- 결정 (10/2 개정)
  - 학생 프로필에 **사는 곳**(서울·인천·경기 시·군·구, 선택)을 둔다. 정확한 주소는 받지 않는다. 저장은 다른 프로필 값과 같이 [저장]+동의 때만.
  - 직무 상세에서 통근을 부르면 서버가 카카오만 부른다.
    1. **카카오 로컬 주소 검색**(`GET https://dapi.kakao.com/v2/local/search/address.json`)으로 좌표를 구한다. 출발 = 사는 곳 '시도 시·군·구'(예: '서울 노원구')의 대표 좌표, 사는 곳이 없으면 서경대(설정값). 도착 = 근로지 주소를 도로명 + 건물번호까지만 남긴 검색어(건물명·층·호수 제거, `AddressQuery`). 못 찾으면 첫 쉼표 앞 원문으로 한 번 더 찾는다. 출발·도착은 동시에 부른다.
    2. **카카오 대중교통 길찾기**(`GET https://dapi.kakao.com/v2/routing/publictraffic`)를 1번 부르고, 받은 경로 중 **가장 빠른 경로**(totalTime 최소, 같으면 환승이 적은 쪽)를 쓴다. 카카오 문서에 경로 정렬 기준·정렬 옵션이 없어 첫 경로가 가장 빠르다는 보장이 없다(10/2 배포 확인 때 첫 경로를 쓰면 시간이 전반적으로 길게 나와 바꿈).
  - 결과(좌표·시간·경로)는 **DB·캐시·시드 어디에도 저장하지 않는다.** 부를 때마다 쓰고 버린다. 그래서 `area`·`workplace`의 좌표 칸을 없앴다(V2).
  - 목록 카드(추천·지망)에는 통근을 넣지 않는다.
- 처음 결정 (10/1): 출발·도착 좌표는 행정안전부 도로명주소 좌표제공 API로 오프라인에서 구해 시드로 넣고, 카카오 로컬 API는 쓰지 않는다. → 도로명주소 키(검색 API + 좌표제공 API 2개) 발급이 10/1부터 대기였고, 그동안 통근이 전부 '근무지 위치 없음'이었다. 카카오 주소 검색은 저장만 하지 않으면 쓸 수 있어 10/2에 바꿨다(사용자 결정). 도로명주소 키는 받지 않는다.
- 이유
  - 학생에게 의미 있는 건 서경대가 아니라 사는 곳에서 근로지까지의 시간이다.
  - 카카오 운영정책은 API 결과와 결과로 만든 가공 데이터를 DB·캐시에 저장하거나, 경로를 미리 조회해 보관하는 것을 금지한다(데브톡 공식 답변 2026-09-17). 로컬 API 결과도 저장할 수 없다. 그래서 미리 계산이 아니라 조회할 때마다 계산하고, 좌표도 그때 구한다.
  - 키가 하나(`KAKAO_REST_API_KEY`)로 끝난다. REST 키라 IP 등록이 없어 Render에서 바로 부를 수 있다.
  - 무료 한도: 대중교통은 개발자 계정에서 카카오맵을 **처음** 켠 앱 하나에 하루 1,000건(2026-07-21 정책, 두 번째 앱부터는 비즈월렛·건당 10원). 로컬 API는 같은 정책에서 기존 제공량을 유지하고(공지), API마다 하루 10만 건이다(데브톡 답변). 조회 1번에 주소 검색 1~3건이라 병목은 대중교통이다.
    - 공지: https://devtalk.kakao.com/t/api-notice-on-new-kakao-map-api-features-and-free-quota-policy/150222
    - 로컬 API 한도 답변: https://devtalk.kakao.com/t/api/150689
  - ODsay는 결과 저장에 회사의 사전 동의가 필요하고 무료 하루 30건이라 맞지 않는다(ADR-0002 개정).
- 결과
  - 실행 중 외부 호출은 카카오 두 종류(주소 검색·대중교통)다. 실패·한도 초과면 통근 칸만 '불러오지 못했어요'로 두고 나머지 화면은 그대로다(200 + `available: false`, `docs/api/README.md`).
    - 근로지 주소가 없거나 카카오가 못 찾으면 `NO_WORKPLACE`. 사는 곳을 못 찾거나 호출이 실패하면 `PROVIDER_ERROR`, 한도 초과면 `LIMITED`.
  - 호출 제한: 통근 조회 계정당 1시간 30회, 서버 전체 하루 900회(대중교통 무료 1,000건 안에서 멈춘다). 막히면 주소 검색도 부르지 않는다. 카카오 호출 하나마다 3초를 넘기면 포기한다(주소 검색 둘은 동시, 길찾기는 그다음).
  - 직무 상세의 `workplace.hasCoordinates`는 근로지 주소가 있으면 true다(이름은 계약을 바꾸지 않으려고 그대로 둔다).
  - 카카오 API에는 출발 시각 값이 없다. 조회 시각에 따라 결과가 바뀌는지는 낮·밤에 한 번씩 `KakaoLiveCheck`로 확인한다.
  - 키: `KAKAO_REST_API_KEY`(Render 환경변수). 카카오맵을 켠 적 없는 팀 계정에서 앱을 만든다. 비즈월렛은 연결하지 않는다(한도를 넘으면 과금 대신 실패하도록).
  - 로그에 사는 곳 코드·검색어·좌표를 남기지 않는다.
  - 사는 곳 목록(`area`)은 서울·인천·경기 시·군·구 이름과 행정표준코드뿐이라(좌표 없음) 공공 코드표로 시드한다 — 10/2 2026-10-01자 법정동코드로 83곳(인천 7/1 개편 반영, `pipeline/seed/areas.py`).
- 다시 볼 때: 하루 1,000건을 넘는 운영 단계, 또는 카카오 운영정책·무료 쿼터가 바뀔 때.
