# ADR-0019 기관 로고 표시(미리 받아 정적 파일로, 응답에는 경로만)

- 상태: 확정 (2026-10-05 사용자 요청)
- 결정
  - 2026-2 참여기관 18곳의 로고를 미리 받아 `src/main/resources/static/logos/{기관 id}.png`로 저장소에 넣고, API 서버가 `/logos/{id}.png`로 내보낸다. 로그인 없이 받고(`/api` 밖), 캐시는 하루.
  - 기관 요약 `InstitutionRef`와 직무 상세의 `institution`에 `logoPath`(예: `/logos/3.png`)를 더한다. 파일이 없으면 null이고, 화면은 기관명 첫 글자로 대신한다. 프론트는 API 기본 주소 뒤에 붙여 `<img>`로 띄운다.
  - 파일 이름이 기관 id라 DB·시드는 바꾸지 않는다. 기관이 늘면 같은 이름 규칙으로 파일만 더한다.
  - 출처는 회사 홈페이지·채용 페이지·브랜드 사이트(17곳)와 센터가 배포한 기관 소개서(세정 1곳)다. 기관별 출처와 다듬은 방법은 `pipeline/logos/README.md`.
- 이유
  - 실행 중에 회사 사이트에서 받으면 외부 호출이 늘고(ADR-0002), 18곳 중 여러 곳이 봇 차단·리다이렉트·서비스 종료(네이버 modoo)라 시연 중 이미지가 깨진다.
  - 파비콘 서비스(구글 s2 등)는 해상도가 낮고 없는 곳은 기본 아이콘을 준다.
  - 로고는 기관을 알아보게 하는 표시로만 쓴다(목록·상세의 기관명 옆). 변형하지 않고 배경만 투명으로, 흰 글자 로고는 같은 모양 그대로 어두운 색으로만 바꿨다.
- 다시 볼 때: 회차가 바뀌어 기관이 바뀔 때, 기관이 로고 사용을 원하지 않을 때(그 파일만 지우면 null로 돌아간다).
