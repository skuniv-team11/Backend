# ADR-0042 지원서의 본인 서명은 신청서 성명(한글)과 같아야 낼 수 있다

- 상태: 확정 (2026-10-29 — 박경원 요청: 10/29 점검 '신청서에 적은 이름과 서명 이름이 다르면 제출이 안 돼야 한다'. PR 병합으로 확정한다)
- 문제
  - 내기 전 확인(`checklist`)의 `SIGNATURE`는 서명이 2자 이상인지만 봤다. 그래서 성명(한글)이 '예시 학생'인데 서명을 '다른 학생'으로 적어도 승인 요청과 내기가 됐다.
  - 별지 제5호 신청서와 개인정보 동의서의 서명은 신청인 본인 서명이다. 다른 이름으로 낸 지원서가 학과(부)장 승인과 센터 접수까지 가면 서식의 뜻이 깨진다.
- 결정
  - `SIGNATURE`는 서명과 성명(한글)이 공백을 빼고 같을 때만 끝난다(2자 이상). '예시학생'과 '예시 학생'은 같다.
  - 다르면 내기(#41)가 지금처럼 400 `APPLICATION_INCOMPLETE`로 막고, 빠진 항목 문구는 "본인 서명은 신청서의 성명(한글)과 같게 적어 주세요"다.
  - 응답 모양은 그대로다. 저장(#38)과 승인 링크 만들기(#40)는 지금처럼 막지 않는다(쓰는 중에는 다를 수 있다). 다른 이름으로 승인을 받았어도 서명을 고치면 승인이 풀려 다시 받아야 낼 수 있다. 프론트는 서명 칸에서 바로 알려 준다.
- 이유
  - 서명을 따로 받는 이유는 본인 확인이다. 서버의 내기 전 확인 한 곳에서 막으면 프론트·승인·접수가 같은 기준을 쓴다.
  - 승인 해시에 성명과 서명이 모두 들어 있어, 승인 뒤 둘 중 하나를 바꾸면 승인이 풀린다(`STALE`). 새 규칙과 어긋나는 승인은 남지 않는다.
- 남은 것
  - 손글씨·이미지 서명은 받지 않는다(이름을 적는 전자서명만).
- 확인
  - `InternshipUnitTest`: 서명 '예시학생'은 성명 '예시 학생'과 같아 끝남, '다른 학생'은 안 끝남, 1자·신청인 없음은 안 끝남.
- 다시 볼 때: 서식 개정으로 서명 방식이 바뀔 때, 학교 계정 로그인으로 실명을 받을 때.
