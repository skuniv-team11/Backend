# ADR-0012 학교 규정은 두 가지만 판정하고 나머지는 안내로 둔다

- 상태: 확정 (2026-10-01)
- 근거 자료: 2026학년도 2학기 표준 현장실습학기제 학생 모집안내(진로취업처). 사전교육 자료(2026-08-26)는 선발 뒤 OT 자료라 지원 자격이 없다.
- 결정
  - 판정 1층(`SCHOOL_RULE`)은 두 가지다. ① 이수 학기 4학기 이상(`completedSemesters`) ② 졸업예정자는 방학 과정(`course` = `VACATION`) 불가(`graduationExpected`). 둘 다 지금 프로필 입력으로 판정한다.
  - 모집안내의 나머지 참여 제한 네 가지 — 휴학·수료·학사학위취득유예·대학원생(다음 학기 복학 예정 휴학생은 가능), 현장실습 학점 18학점 초과, 재직 중(산업체위탁·재직자특별전형), 부정 실습 제재 — 는 묻지도 저장하지도 않는다. 프로필·직무 상세·추천 0개 화면에서 여는 '학교 규정 4가지는 직접 확인해요' 시트로 안내만 한다.
  - 학과(부)장 승인·서명(전자+자필, 복수전공 학점 인정이면 두 학과장)은 판정이 아니라 절차다. 내 지망 '다음 할 일'(P0)과 지원 준비 체크리스트(P1)에 둔다.
- 이유
  - 네 가지는 직무마다 다르지 않다. 걸리면 40개가 전부 지원 불가가 될 뿐이라, 직무별 판정으로 얻는 정보가 거의 없다.
  - 학적·재직·제재 이력은 민감하고, 묻는 순간 수집이 된다. 필수 수집을 최소로 둔 원칙(ADR-0008, 감점 07)과 맞춘다.
  - 새 입력이 없으니 프로필 API·DB 스키마·화면 입력칸을 바꾸지 않는다.
- 결과
  - `docs/api/README.md` 판정 절에 학교 규정 행 두 개를 적었다. 응답 모양은 그대로다.
  - 방학·학기 연계 과정(`VACATION_SEMESTER`)이 '계절제'에 드는지는 공지에 없다 → 센터 확인 항목. 확인 전에는 졸업예정자 계절제 행을 붙이지 않는다.
  - 화면: Claude Design 캔버스·Figma에 '학교 규정 4가지' 시트와 링크 세 곳, 프로필 이수 학기 힌트, 내 지망·지원 준비의 학과장 서명 문구를 넣었다(10/1).
- 다시 볼 때: 다른 학교·사업으로 넓힐 때(규칙 세트를 회차 데이터로 옮김), 또는 센터가 연계 과정 답을 줄 때.
