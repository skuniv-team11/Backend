# ADR-0023 판정 이유 줄마다 원문 출처를 붙인다

- 상태: 확정 (2026-10-07 결정 — '확인 필요 같은 것도 다 근거가 있는지' 점검 뒤)
- 문제
  - 판정 이유 줄(`reasons[]`)은 요건과 내 값만 줬다. 예: '학년 4학년 / 내 3학년'. 그 요건이 어느 문서의 어느 글에서 왔는지는 없었다.
  - AI가 쓴 추천 이유에는 원문 인용(`citations`)이 붙는데, 규칙이 낸 판정에는 근거가 없었다. 화면 설계의 '판정 이유' 패널과 발표의 '모든 값에 원문'이라는 말과도 맞지 않았다.
  - 자격증 줄에만 운영계획서 근거를 붙였다(ADR-0021).
  - 검토 알림(`alerts`)은 쪽·인용은 주는데 문서 이름이 없었다. 화면이 '2쪽'만 보여 줄 수 있었다.
- 결정
  - **판정 이유 줄마다 `citation`**(`{sourceType, documentTitle, page, quote}`, 추천 근거 Citation과 같은 모양)을 붙인다. 판정이 실제로 쓴 값의 원문이다.

    | 줄 | 출처 | `sourceType` | `page` |
    |---|---|---|---|
    | 이수 학기 | 학생 모집안내 '4학기 이상 수료한 재학생(편입생의 경우 본교에서 1학기 이상 이수한 학생)' | `SCHOOL_NOTICE` | null(웹 공지) |
    | 졸업예정자 계절제 | 학생 모집안내 '졸업예정자의 계절제 참여 불가' | `SCHOOL_NOTICE` | null |
    | 학년 · 학점 · 선호 전공 | 참여기관 리스트 칸 원문(예: '학년 : 3, 4학년', '학점 3.5 이상') | `INSTITUTION_LIST` | null(엑셀) |
    | 포트폴리오 | 리스트의 '포트폴리오 필수 제출'. 리스트에 없고 계획서에만 있으면 계획서 쪽·인용 | `INSTITUTION_LIST` / `OPERATION_PLAN` | null / 쪽 |
    | 자격증 | 운영계획서 쪽·인용(사람이 확인한 고침, ADR-0021) | `OPERATION_PLAN` | 쪽 |

  - 판정 값은 리스트를 기준으로 하므로(ADR-0014: 학년·학점·선호 전공은 센터 리스트 기준), 출처도 리스트 칸이다. 계획서와 다르면 지금처럼 검토 알림(`LIST_MISMATCH`)이 두 값을 보여 준다.
  - 학교 규정 문장은 2026-2 진로취업처 공지(2026. 6. 15. 게시)에서 글자 그대로 옮겨 규칙과 같은 곳(`EligibilityRules`)에 둔다. 규칙(4학기)도 코드에 있으니 같이 바뀐다.
  - 리스트 칸과 계획서 출처는 시드 `requirement_source`(DB V6)에 둔다. `build_seed.py`가 리스트 칸에서 그 줄을 찾아 넣고(앞의 ■·- 글머리표만 뗌), 못 찾으면 멈춘다. 2026-2는 103행이다(학년 40 · 선호 전공 40 · 학점 17 · 포트폴리오 3 · 자격증 3).
  - 알림으로 새로 만든 줄(원래 줄이 없던 항목)에는 `citation`이 없다. 알림이 두 원문을 갖고 있다. 원래 줄이 알림으로 '확인 필요'가 되면 원래 출처가 남는다.
  - **검토 알림에 `documentTitle`**(예: '소서 운영계획서')을 더한다. `pageA`·`quoteA`(문서 안 불일치면 `pageB`·`quoteB`도)가 있는 문서다. 리스트 쪽 값은 지금처럼 `description`에 있다.
  - `sourceType` 코드에 `INSTITUTION_LIST`(참여기관 리스트) · `SCHOOL_NOTICE`(학생 모집안내)를 더한다. `source_document.kind`(운영계획서·수기)는 그대로다. 리스트와 모집안내는 쪽 단위 문서가 아니라서 문서 테이블에 넣지 않았다.
- 쓰지 않은 것
  - 원문 파일·공지로 가는 링크: 원본은 학교 계정으로만 열리고, 원문 PDF는 띄우지 않는다는 원칙(AGENTS.md)과 같다.
  - 리스트를 `source_document`에 문서로 넣기: 쪽 수가 필수이고(`page_count > 0`) 기관마다 한 문서라는 제약이 있어, 테이블 뜻을 바꾸지 않고 출처 테이블을 따로 뒀다.
- 다시 볼 때: 새 회차 모집안내가 나오면 `EligibilityRules`의 학교 규정 문장과 문서명을 함께 바꾼다. 리스트 서식(칸 이름 '선호전공학년'·'비고')이 바뀌면 `build_seed.py`가 멈추니 그때 고친다.
