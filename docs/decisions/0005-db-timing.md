# ADR-0005 DB는 Render 무료 Postgres, 10/15 이후 생성

- 상태: 확정 (2026-09-30)
- 결정: 배포 DB는 Render 무료 Postgres를 10/15 이후에 만든다(30일 뒤 만료 → 11/14까지). 그 전은 로컬 Postgres 18(docker compose). 스키마는 Flyway, 데이터는 시드 스크립트로 언제든 다시 만든다.
- 이유: 11/2~11/9 1차 평가(공개 링크)와 11/12 최종 발표까지 살아 있어야 한다. 무료 DB는 백업이 없고 예고 없는 점검이 있어 재생성 가능해야 한다.
- 다시 볼 때: 발표 이후 운영을 이어갈 때(유료 전환).
