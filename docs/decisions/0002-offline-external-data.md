# ADR-0002 외부 데이터는 오프라인에서 미리 계산

- 상태: 확정 (2026-09-30)
- 결정: 국세청 상태조회, ODsay 통근시간, NCS, 국민연금, 교육통계는 `pipeline/`에서 로컬로 받아 시드로 넣는다. 서비스 실행 중 외부 호출은 Claude(추천 설명)와 임베딩만.
- 이유: ODsay 서버 키는 IP 5개까지 등록되는데 Render 아웃바운드 IP는 리전 공유 대역이다. ODsay 무료 하루 30건. 대상 기관이 18곳이라 미리 계산이 충분하다. 시연 중 외부 장애를 없앤다.
- 다시 볼 때: 학기마다 기관이 바뀌는 운영 단계.
