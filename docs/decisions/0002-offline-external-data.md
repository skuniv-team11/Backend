# ADR-0002 외부 데이터는 오프라인에서 미리 계산

- 상태: 확정 (2026-09-30), 개정 (2026-10-01 — 통근 시간은 [ADR-0007](0007-commute-kakao-live.md)로 옮김), 개정 (2026-10-02 — 임베딩은 쓰지 않음, [ADR-0018](0018-recommendation-rule-keyword.md))
- 결정: 국세청 상태조회, NCS, 국민연금, 교육통계, 주소 좌표(행정안전부 좌표제공 API)는 `pipeline/`에서 로컬로 받아 시드로 넣는다. 서비스 실행 중 외부 호출은 Claude(추천 설명), 카카오 대중교통(통근 조회, ADR-0007) 둘뿐이다(임베딩은 E5 결과로 쓰지 않는다, ADR-0018).
- 이유: 시연 중 외부 장애를 줄인다. 위 공공 데이터는 저장·가공이 허용돼 미리 계산해 둘 수 있다.
- 10/1 개정: 처음에는 ODsay 통근시간(서경대 → 근로지)도 미리 계산해 시드로 넣으려 했다. 그런데 ODsay 운영정책(제4조 5항 10호)은 회사의 사전 동의 없이 결과 데이터를 저장·가공하는 것을 금지한다. 무료 하루 30건·서버 키 IP 등록이라 실행 중 호출에도 맞지 않는다. 그래서 통근은 사는 곳 기준 카카오 실시간 조회로 바꿨다(ADR-0007). `pipeline/e6_external/odsay_commute.py`의 결과(`commute.csv`·`odsay_cache/`)는 시드에 쓰지 않는다.
- 다시 볼 때: 학기마다 기관이 바뀌는 운영 단계.
