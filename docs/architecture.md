## MVP 화면 (학생 흐름 + 센터 현황판)
1. 프로필 입력(예시 프로필 불러오기, 사는 곳은 시·군·구 선택) → 2. 자격 판정 3층(학교 규정 → 지원 불가 / 기관 조건 → 확인 필요 / 선호 전공 → 참고 표시, 모두 이유와 함께) → 3. 적합도 추천 + 근거 인용 → 4. 직무 상세(AI 추출값 ↔ 근거 쪽·인용문, 사는 곳 기준 통근시간 — 카카오 실시간, 사는 곳이 없으면 서경대 기준) → 5. 1~3지망 점검(몰림 경고 + 빈 자리 제안, 모집기간 리플레이, 가상 신호 표시)
6. 센터 현황판(읽기 전용 1화면, P0): 직무별 신호 대비 정원, 구조적 위험 요인, 문서 검토 알림, 지난 학기 0명 이력
P1: 체크리스트 → NCS 직무 풀이
