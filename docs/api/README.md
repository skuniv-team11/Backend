# API 계약

프론트는 이 문서의 응답 예시로 목업을 만들고, 백엔드는 이 형태를 지킨다. 형태를 바꾸려면 이 문서를 먼저 고친다.

## 공통
- 기본 경로 `/api`, JSON, 필드는 camelCase, 날짜는 ISO 8601(`2026-07-18`, `2026-09-30T14:00:00+09:00`)
- 오류: HTTP 상태 코드 + `{"code": "ELIGIBILITY_INPUT_INVALID", "message": "사람이 읽는 설명"}`
- 학생 입력은 요청 본문으로만 받고 저장하지 않는다

## 목록
| 메서드 | 경로 | 설명 | 예시 |
|---|---|---|---|
| GET | `/api/ping` | 배포 연결 확인 | [ping.json](ping.json) |
